# fMRIViz
A visualization end for models on functional magenetic resonance imaging (fMRI) modality

## Atlas Data Licensing

This viewer supports multiple anatomical atlases. Some atlases impose
restrictions on redistribution.

Brainstem Navigator data is NOT redistributed with this software.
Users must obtain it separately under the original license.

Brainnetome Atlas is licensed for non-commercial use only.

## Restricted Data

This repository supports optional private extensions.
Restricted atlases and subject data are not included.
